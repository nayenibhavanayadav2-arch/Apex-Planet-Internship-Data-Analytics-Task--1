# ApexPlanet Data Analytics Internship - Task 1

## 📌 Project Title
Data Cleaning and Preprocessing using Python

## 📖 Project Overview
This project was completed as part of the **ApexPlanet Software Pvt. Ltd. Data Analytics Internship**.

The objective of this task is to access the dataset, assess its quality, clean and preprocess the data, and prepare it for further analysis using Python and Pandas.

---

## 🎯 Objectives

- Access and understand the dataset
- Perform data quality assessment
- Handle missing values
- Remove duplicate records
- Standardize data formats
- Prepare an analysis-ready dataset
- Generate data quality reports

---

- Jupyter Notebook
- Microsoft Excel

## 📊 Steps Performed

### 1. Data Access & Familiarization
- Loaded Excel dataset
- Examined rows and columns
- Reviewed data types
- Understood dataset structure

### 2. Data Quality Assessment
- Checked missing values
- Identified duplicate records
- Reviewed inconsistent formatting
- Examined data types

### 3. Data Cleaning & Transformation
- Removed duplicate records
- Filled missing values
- Standardized column names
- Trimmed extra spaces
- Converted data types where required
- Saved cleaned dataset
